Portfolio thresholds

What the sites overview counts as stable growth, declining and high invalid traffic. Applies to every site of this instance; lifecycle stages and the “Needs attention” queue update on the next refresh (within 5 minutes).

Stable growth
A site is growing when it had at least this many clean visitors in the last 7 days and did not drop more than the allowed dip vs the 7 days before.
Declining
A site is declining when its clean visitors over the last 28 days fell by more than this share vs the 28 days before. Takes precedence over growing.
High invalid traffic
Raise an attention item when the invalid share (bots + suspect traffic) of a site is above this percentage. Critical while ad protection is off.

API tokens

— credentials for the CLI, the MCP server (so your own chatbot can query this data) and other integrations. Read-only tokens can only query reports; read/write tokens (all sites only) can also create, update and archive sites and funnels — give those only to trusted services. Shown once at creation.

Copy it now — it cannot be shown again.

Site templates

— presets for sites created through the API (POST /v1/sites with "template"): timezone, engagement threshold, ad protection, AdSense client and default funnels. Empty fields fall back to the usual defaults; fields in the API request override the template.

Crawler directory

— optional. Import a public bots-and-agents catalogue to label crawler traffic by kind (search / AI training / SEO / ads). Classification only: it never changes scoring, verdicts or ad protection.

Cloudflare edge requests

— optional, advanced. The tracking script only sees visitors whose browser ran JavaScript. AI crawlers and scrapers fetch your HTML and leave, so they never appear. Cloudflare saw all of them: add a read-only API token and the daily job pulls those request counts, so your dashboard can show what the script missed. Leave it empty and nothing changes.

In the Cloudflare dashboard: My Profile → API Tokens → Create Token → Create Custom Token. Give it exactly these two permissions, both read-only:
Zone · Zone · Read
Zone · Analytics · Read
Under Zone Resources choose the zones your sites are on (or all zones in the account), then create the token and paste it below. Open Cloudflare API Tokens ↗

Storage & retention

— raw event rows are what fills the D1 database (roughly 0.8 KB each with indexes; a pageview produces several once behavior heartbeats are counted). Dashboards read from rollups that are kept forever; the windows below only decide how far back visitor journeys and the suspicious-visitor drill-down reach. Set them in config.local.toml [retention], then redeploy the cron and console workers.
