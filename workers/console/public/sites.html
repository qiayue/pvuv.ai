Cloudflare edge requests
         — optional, advanced. The tracking script only sees visitors whose browser ran JavaScript. AI crawlers and scrapers fetch your HTML and leave, so they never appear. Cloudflare saw all of them: add a read-only API token and the daily job pulls those request counts, so your dashboard can show what the script missed. Leave it empty and nothing changes.

      

        In the Cloudflare dashboard: My Profile → API Tokens → Create Token → Create Custom Token. Give it exactly these two permissions, both read-only:
        
Zone · Zone · Read
Zone · Analytics · Read

        Under Zone Resources choose the zones your sites are on (or all zones in the account), then create the token and paste it below.
        Open Cloudflare API Tokens ↗
      

      

      

      

      

      
      

    

    

      
Storage & retention
         — raw event rows are what fills the D1 database (roughly 0.8 KB each with indexes; a pageview produces several once behavior heartbeats are counted). Dashboards read from rollups that are kept forever; the windows below only decide how far back visitor journeys and the suspicious-visitor drill-down reach. Set them in config.local.toml [retention], then redeploy the cron and console workers.
